# 🔨 Secret Auction Program

A simple command-line **Secret Auction Program** built with Python.

This project allows multiple bidders to enter their bids privately and determines the highest bidder at the end of the auction.

## 📌 About the Project

This project was created as part of my **100 Days of Python** learning journey.

The main goal of this project was to practice Python fundamentals such as dictionaries, functions, loops, conditional statements, user input, and finding the highest value in a dictionary.

## ⚙️ How It Works

1. The program asks for the bidder's name.
2. The bidder enters their bid amount.
3. The bid is stored in a dictionary.
4. The program asks whether there are other bidders.
5. If another bidder exists, the previous information is cleared from the screen.
6. Once all bidders have entered their bids, the program compares all bids.
7. The bidder with the highest bid is declared the winner.
